## 🌟 About Devora

Starting to learn programming can feel confusing, especially when you don't know where to begin or which path to follow.

**Devora** aims to make that journey easier, clearer, and more enjoyable.

It's a beginner-friendly programming learning platform that guides learners from the basics toward different programming specializations through an engaging and interactive experience.

Our goal is simple:

> Make learning programming less intimidating and more exciting.

---

## 🚀 Getting Started

Follow these steps to run Devora locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/devora-learning-platform.git
```

### 2. Navigate to the project directory

```bash
cd devora-learning-platform
```

### 3. Run the project

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.
